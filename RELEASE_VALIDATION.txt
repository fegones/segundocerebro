LÍMITES DEL PROVEEDOR
La API documentada de Google no expone chat completo/historial ni todos los artefactos de NotebookLM.
El índice cifrado solo dispone del contenido importado manualmente o de texto que la API
realmente devuelva en respuestas GetSource. No se simula contenido inaccesible.

PRIVACIDAD Y ALCANCE
El servidor MCP puede imponer selección de cuadernos autorizados. Este control no
restringe otras herramientas independientes que el agente tenga habilitadas.
El índice cifra contenido, pero los metadatos locales de cuadernos/fuentes no están cifrados.

El manifiesto SHA256SUMS.txt verifica los archivos de esta entrega, no la
seguridad de las dependencias ni la autenticidad del servicio remoto.
