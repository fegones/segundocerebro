**Titular de copyright declarado para el código de esta distribución:** Felipe Carlos González Espinoza (2026).  
**Licencia de esta distribución:** MIT, según `LICENSE`.

Este proyecto es la evolución de implementaciones previas del mismo producto: un cliente local para API pública de Gemini Notebook, agentes MCP y funciones de consulta documental. La versión 1.3.0 incorpora selección entre varias cuentas, auditoría documental, recuperación extractiva y medidas de control sobre el conector.

El código y la documentación han sido preparados con asistencia de inteligencia artificial. Se usaron especificaciones públicas de API y patrones técnicos de software para construir la implementación. El repositorio publicable se prepara sin incluir un directorio `.git` anterior, sin reutilizar el historial de commits de repositorios externos y sin credenciales ni archivos personales.

**Alcance de la atribución:** la titularidad declarada no supone apropiación de bibliotecas de terceros ni garantía absoluta de originalidad verificable por simple inspección automatizada. La licencia MIT del proyecto rige el código sobre el que el titular dispone de derechos; cualquier fragmento externo incorporado en el futuro debe registrarse y distribuirse respetando sus propios avisos y obligaciones de licencia. Las bibliotecas instaladas por `pip` mantienen sus licencias individuales.

**Requisitos de auditoría:** conservar registros verificables de cambios posteriores, ejecutar pruebas y controles de secretos, publicar dependencias y sus avisos cuando corresponda, y documentar hallazgos y remediaciones sin encubrir información relevante.

Las cuentas Google, tokens OAuth, claves API, índices documentales personales y exportaciones se crean exclusivamente en la estación del usuario durante el funcionamiento, no forman parte de los archivos públicos distribuidos.
