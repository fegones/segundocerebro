# Contribuciones

Toda contribución debe incluir pruebas reproducibles, documentación de alcance e impacto sobre privacidad. No enviar datos personales, tokens OAuth, historiales de Notebook o claves API en pull requests. Antes de incluir código de terceros verifique su licencia y conserve los avisos requeridos. Mantenga el servidor MCP local por defecto, sin exponer puertos, y requiera consentimiento para escrituras.
